## 1. 채널 컨셉

한 줄 정의: **"작품 한 편 뒤에 숨은 사람 이야기 한 개"**

- 줄거리 요약·결말 포함형은 전면 배제 (저작권/재사용 콘텐츠 이중 리스크)
- HymnStory와 동일 구조: 작품 = 찬송가, 비화 = 그 뒤의 이야기
- 파이프라인 재활용 가능 (리서치 → 대본 → 대본확정 게이트 → 장면 → 영상 → 발행)

### 콘텐츠 각도 (우선순위 순)

1. 원작자·작가 이야기 — 소설/원작 웹툰 작가의 개인사, 집필 계기
2. 제작 계기 — 실제 사건, 감독의 개인 경험
3. 촬영 비화 — 사고, 즉흥 연기, 예산 문제, NG 미담
4. 캐스팅 비화 — 거절한 배우, 무명 시절 발탁
5. 작품 간 비교·연결 — 감독 전작과의 연결점

핵심 원칙: **"남들이 모르는 사실"일수록 가치가 높다.**
이미 나무위키 상단이나 대형 채널에 나온 비화는 후보에서 제외.

## 2. 저작권 규정 (조사 결과)

### 확인된 사실

- 안전한 퍼센트/초 수 기준은 법에도 유튜브 정책에도 존재하지 않음
- 판단 기준은 "양"이 아니라 "성격": 원본을 대체하는가, 내 해설이 주(主)인가
- 한국 저작권법 제28조(인용), 제35조의5(공정이용) 존재하나 미국 Fair Use보다 훨씬 엄격, 판례 적음
- 한국에서 실제 채널 폐쇄·수익 회수 사례 다수 (권리자 직접 신고)

### 금지 사항 (채널 리스크 직결)

- 결말 포함 요약, 몰아보기 형태
- 무음 구간 잘라내기 등 Content ID 회피 편집
  - 탐지는 피할 수 있으나 권리자 수동 신고에는 전혀 방어 안 됨
  - 유튜브 가이드라인상 "재사용 콘텐츠" 조항에도 저촉

### 허용 범위 (사용할 소스)

- 배급사 공식 예고편 (홍보 목적 공개 → 가장 안전한 선)
- 보도자료용 스틸컷 (배급사 배포분)
- 시사회·레드카펫 등 공식 행사 영상
- 감독·배우 공식 인터뷰 클립
- 라이선스 구매 이미지 (Getty, Shutterstock 등)
- 퍼블릭 도메인 자료 (작가·원작자 등 오래된 인물)

주의: 배우 사진의 저작권은 촬영 언론사/스튜디오에 있음. 별개 문제이며
실제로 가장 자주 걸리는 지점. 인물 중심 구성 시 라이선스 이미지 필수.

## 3. 영상 스펙

### 길이: 30~60초 권장. 상한 고정 없음.

- 억지로 늘리지 않는다. 할 말 끝나면 끊는다.
- 30초 이내가 완주율 최고이나, 스토리텔링·교육형은 60~90초도 유효
- 알고리즘 핵심 신호는 완주율이 아니라 총 시청 시간
  (완주율 90% 15초 < 완주율 40% 3분 사례 존재)
- 30~60초는 "총 시청시간 확보"와 "완주율 유지"의 교집합

### 비율: 9:16 (1080x1920)

### 구성

- 0~2초: 훅 (남들이 모르는 사실을 먼저 던진다)
- 2~10초: 작품 특정 (예고편 클립으로 어떤 작품인지 즉시 인지)
- 10~45초: 비화 본문
- 45~60초: 마무리 + 다음 편 유도

### 자막

화면에 태워 넣는다(번인). 자막 애니메이션 적용 시 유지율·완독률 상승 근거 있음.
자막 없는 버전은 실험 가치 낮다고 판단 → 제외 (소리 끄고 보는 시청자 비중 高)

## 4. 시장 및 채널 구조

**결정: 한국 작품을 소재로, 한국어 채널 + 영어 채널 2개 운영**

> ※ `파이프라인_설계.md` 4.1에서 이 결정에 대한 반론 제기됨.
>   1단계는 한국어 채널 단독, 각도 검증 후 영어 채널 추가를 권고.

### 근거

- 한국 작품 비화는 한국어 기사·인터뷰에 깊게 축적 → "남들이 모르는 사실" 확보 가능
- 미국 작품을 영어로 다루면 전문 채널 수백 개와 경쟁, 차별점 소멸
- 넷플릭스 효과로 한국 드라마·영화에 미국 시청자 관심 존재
- 영어 채널로 미국 광고 단가(한국의 2~3배) 확보

### 채널 구성

- 채널 A: 한국어 나레이션 + 한국어 번인 자막
- 채널 B: 영어 나레이션 + 영어 번인 자막
- 이미지·클립 시퀀스는 완전히 동일, 오디오/자막 레이어만 교체 후 재렌더링
- 채널 3개(자막 없는 다국어 오디오 버전) 안은 폐기
  - 초기 노출 분산, 2주 단위 지속률 판단 데이터가 3분할되어 판단 불가

### 중복 콘텐츠 리스크 대응

- 언어별 현지화 버전은 유튜브가 문제 삼는 "재사용 콘텐츠"에 해당하지 않음
- 단, 다음 두 가지를 반드시 지킬 것:
  1. 채널명·채널 설명·영상 제목·설명을 각 언어권에 맞게 완전 현지화
  2. 나레이션은 번역이 아니라 해당 언어권 화법으로 재작성 (번역기 티 제거)

## 5. 유튜브 다국어 기능 (참고)

### 확인된 사실

- 다국어 오디오 트랙: 직접 녹음한 트랙을 언어별로 업로드 가능.
  시청자의 시청 기록 기반으로 선호 언어 트랙 자동 선택, 플레이어에서 수동 변경 가능.
  번역된 제목·설명 등록 시 해당 언어 검색에도 노출됨.
- 자동 더빙: 27개 언어 지원, 2026년 초 Expressive Speech 추가(8개 언어).
  YPP 및 고급 기능 사용 크리에이터에게 제공.
- 자막은 자동 생성 안 됨 → 언어별 SRT 별도 업로드 필요

### 본 프로젝트 적용 여부: 미사용

- 번인 자막 방식을 택했으므로 영상 파일이 언어별로 분리됨
- 따라서 다국어 오디오 트랙 기능과 병용 불가
- 향후 번인 자막을 포기할 경우 재검토 대상

## 6. 초기 발행 계획

### 1단계 (초기 10편): 신작 위주

- 목적: 노출 확보 + 어떤 각도가 먹히는지 실험
- 신작 20편 안은 폐기 (비화 소스가 얇아 내용이 억지스러워질 위험)

### 2단계 (11편 이후): 신작 1편 / 구작 1편 교차

- 구작 기준: 개봉·방영 5년 이상 경과
- 구작 강점: 비화가 기사·인터뷰로 이미 축적되어 리서치 성공률 높음
- 신작 특성: 검색 수요 폭발하나 2주면 소멸
- 구작 특성: 검색량 낮으나 꾸준히 누적. 쇼츠는 추천 알고리즘 주도이므로 불리함 작음

평가 주기: 2주 단위, 조회수가 아닌 시청 지속률 기준

## 7. 미결정 사항 (다음 세션 논의 대상)

- 훅 문형 템플릿 확정 (도입부 2초 패턴 3~5종)
- 신작 10편 후보 리스트 선정
- 나레이션 TTS 선정 (한국어/영어 각각. 영어는 native 품질 필요)
- 리서치 소스 화이트리스트 구축 (기사·인터뷰 DB화)
- 라이선스 이미지 조달 예산 및 사용 기준
- 채널명 및 브랜딩
- 업로드 케이던스 확정
- 소스 수집 자동화 범위 (예고편·스틸컷 수집 에이전트 설계)
