# 유튜브 채널 운영 타이쿤 — 1단계 프로토타입

설계서 v0.2(Claude Docs「유튜브 채널 운영 타이쿤 — 게임 설계서」)의 1단계 범위에 타이쿤 요소를 더한 플레이 가능한 시제품.

## 실행

- `index.html`을 브라우저로 연다 (서버 불필요, 모바일 세로 화면 기준).
- 한 파일짜리 버전: `node build.js` → `dist/tycoon.html` (휴대폰·메신저 공유용)
- 밸런스 확인: `node sim/simulate.js 20` — 봇이 1배속으로 60분 플레이한 성장 곡선(중앙값).

## 파일

| 파일 | 내용 |
| --- | --- |
| `engine.js` | 게임 규칙 전부. 밸런스 수치는 맨 위 `CONFIG` 하나에 모여 있다 |
| `scene3d.js` | 방 안 장면 3D (Three.js 로우폴리 미니어처 방). 시간대 조명·그림자, 2등신 캐릭터 동작, 보유 장비·공간·수료증, 택배·외주 편집자, 말풍선과 수익 알림 |
| `scene.js` | 2D 픽셀 장면. WebGL을 못 쓰는 기기에서만 대신 쓰임 |
| `vendor/three.min.js` | Three.js r149 (MIT, `vendor/three.LICENSE`) |
| `index.html` | 화면. 브랜드 이름은 `<script id="brands">` 블록에만 있다 (후원 시 이 블록만 교체) |
| `sim/simulate.js` | 밸런스 시뮬레이션 |

## 들어간 것

- 게임 화면: 방 안 장면이 전체 화면. 위에 돈·구독자·체력·호감도와 진행 카드, 아래에 제작·채널·투자·상점·기록 버튼(누르면 아래에서 창이 올라옴). 캐릭터가 기획·편집(책상), 촬영(카메라 앞), 휴식(침대), 알바(외출)를 오가며 일하고, 산 장비·공간·수료증이 방에 그대로 나타난다. 창밖과 실내 조명은 게임 시각에 따라 새벽·낮·노을·밤으로 바뀐다. 방을 탭하면 작업 독려
- 시간: 게임 1일 = 실시간 10초 (1배), 3배·10배, 일시정지. 화면에 게임 날짜·시각 표시
- 핵심 루프: 트렌드 카드 → 기획·촬영·편집 진행 바 → 썸네일 3안 중 선택 → 업로드 → 72시간 피크 조회수 → 정산
- 탭 연타("작업 독려")로 제작 가속 — 체력을 그만큼 씀
- 놔두기 요소: 자동 반복 루틴(주제 선택·제작·업로드·휴식 자동), 편집 외주, 지난 영상 롱테일 수익, 접속하지 않은 동안 정산(25% 효율, 최대 2시간)
- 체력·휴식·번아웃, 편의점 알바(초반 돈 벌이)
- 투자: 촬영 장비 4종 / 컴퓨터 부품 4종(램·SSD·CPU·그래픽카드) / 작업 공간 4단계 / 강의 5종 / 반복 업그레이드 5종
- 수익: 수익 창출 전 제휴 링크, 구독자 1천 + 시청 4천 시간에 광고 수익
- 이벤트: 바이럴, 악플·논란, 알고리즘 개편(30일마다), 장비 할인, 구독자 선물, 소규모 협찬
- 목표(퀘스트) 11개와 보상, 자동 저장
- 모의 결제 상점과 시작 세트 선택 (실제 결제 없음)

## 설계서 v0.2와 달라진 점 (설계서 반영 필요)

| 항목 | 설계서 v0.2 | 시제품 | 이유 |
| --- | --- | --- | --- |
| 조회수 공식 | `B × S^0.8 × …` | `B × (2000 + 20×S)^0.7 × …` | 원래 식은 구독자 0이면 조회수 0이라 게임이 시작되지 않음. 지수 0.8 이상은 후반 폭주 |
| 구독 전환율 | 1%, 품질 80 이상 2% | `0.8% × 품질/60 + 초반 보정 4%×300/(S+300)` | 첫 영상 구독자 수 목표를 맞추고 품질 80 문턱의 급격한 점프 제거 |
| 알고리즘 호감도 | CTR·AVD 7일 이동평균 (2단계) | 업로드마다 `25 + 0.6×품질 + 40×(썸네일-1)` 쪽으로 20% 이동 | 1단계 임시 규칙. 누적식은 100에 고정돼 폭주 |
| 바이럴 | 품질 80 이상, 10~50배 | 품질 80+ 4% / 70+ 1.5% / 그 외 0.5%, 5~20배 | 10~50배는 유료 세트에서 연쇄 폭주 |
| 1단계 목표 | 30분 1만(완료 기준) / 60분 1만(밸런스) 불일치 | 60분 1만 | 사용자 결정 |
| 이벤트 주기 | 3~7일 | 25~50일 (실시간 4~8분) | 3~7일은 30~70초마다 팝업 |
| 결제 모델 | 편의 기능만 | 장비·컴퓨터·공간·강의 묶음 (게임머니로도 살 수 있는 것만). 구독자·게임머니·수익 배율은 팔지 않음 | 사용자 결정 |
| 장비 | 카메라·마이크·조명·편집 PC·소프트웨어 | 편집 PC를 램·SSD·CPU·그래픽카드로 쪼갬, 작업 공간·강의 추가 | 사용자 요청 |
| 그래픽 | 1단계는 CSS 카드만, 스프라이트는 3단계 | 1단계부터 3D 미니어처 방 장면 | 사용자 요청 — 게임처럼 보이는지가 1단계 재미 검증에 필요 |
| 1단계 범위 | 직원·체력은 3단계 | 체력·번아웃·외주·자동 루틴을 1단계에 포함 | 타이쿤식 반복 위임 요소 요청 |
| 파일 구성 | 단일 HTML | `index.html` + `engine.js` | 시뮬레이션과 같은 엔진을 쓰기 위해. 서버 없이 열림 |
