## 2. 확정된 결정

- **채널 2개 동시 운영** (한국어 A / 영어 B, 1편부터) — 사용자 결정. 재논의 불가.
  단 **각도 판정은 채널 A 지표만으로** 한다. 합산하면 "각도 실패"와 "시장 부적합"이 구분 안 됨.
- **게이트 1은 흥미도 기준.** 신선도("남들이 모르는 사실") 기준은 폐기됨.
  쇼츠 시청자는 팬덤이 아니라 "나무위키에 있다 = 시청자가 안다"가 성립하지 않는다.
  나무위키 수록은 탈락 사유 아님. **대형 쇼츠 채널의 동일 소재 영상만 탈락 사유**(경쟁 문제).
- **흥미도 판정법**: 한 문장으로 소리 내어 말했을 때 상대가 "어?" 하고 되묻는가. 유형표는 분류 도구일 뿐.
- **사실 검증(S1)을 대본보다 앞에 둔다.** 저작권 사고는 영상을 내리면 끝나지만
  허위사실·명예훼손은 회복 불가. 한국은 사실적시도 처벌 대상.
- **무얼굴 구성이 표준.** 인물 비화에 얼굴 사진은 불필요. 나레이션이 이야기를 끌고 가고
  화면은 예고편 재활용 + 발언 타이포그래피 + 데이터 도식 + 생성 배경 컷으로 채운다.
  → 다섯 각도 전부 원가 0. 라이선스 구매는 "반전이 외모·이미지에 걸린 비화"에만 발생.
- **자동화 금지 구간**: S1 사실 검증, S2 대본, S2b 영어 대본. 자동화 우선순위는 S5 렌더 → S0 수집.
- **생성 이미지는 배경·분위기 컷만.** 실존 인물 얼굴 생성 금지.

## 5. 버린 접근법 — 전부 사용자가 바로잡은 것

- **"인물 비화엔 얼굴 사진이 필요하고 그건 라이선스 대상"** → 틀림. 얼굴은 필수가 아니다.
  이 전제 때문에 원작자·캐스팅 각도를 고원가로 잘못 분류했고, 원작자 각도를 1단계에서
  뺐다가 되돌렸다.
- **"신선도가 핵심 원칙"** → 틀림. 신선도는 목적이 아니라 대리 지표였다.
  게이트 1·2가 서로 반대로 당기는 구조도 여기서 나왔다(모르는 소재일수록 출처가 얇음).
- **"채널 1개로 시작"** → 사용자가 2개로 결정. 다시 꺼내지 말 것.
- **자막 없는 다국어 오디오 채널 3개안** → 기획서 단계에서 이미 폐기(데이터 3분할).
