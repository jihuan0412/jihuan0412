# 유튜브 채널 운영 타이쿤 — 프로토타입

설계서 v0.2(Claude Docs「유튜브 채널 운영 타이쿤 — 게임 설계서」)를 바탕으로, 1~4단계 범위를 한 번에 플레이할 수 있게 만든 시제품.
수치는 시뮬레이션으로 맞춘 출발점이며 직접 플레이하며 고치는 것을 전제로 한다.

## 실행

- `index.html`을 브라우저로 연다 (서버 불필요, 모바일 세로 화면 기준).
- 한 파일짜리 버전: `node build.js` → `dist/tycoon.html` (휴대폰·메신저 공유용)
- 밸런스 확인: `node sim/simulate.js 12` — 봇이 1배속으로 60분 플레이한 성장 곡선(지역·시작 세트·제작 방식·장르별 중앙값)

## 파일

| 파일 | 내용 |
| --- | --- |
| `engine.js` | 게임 규칙 전부 (DOM 없음). 밸런스 수치는 `CONFIG`와 각 데이터 표(REGIONS, HOUSES, GENRES, AI_PLANS, AI_LEVELS, STAFF_ROLES, EQUIP, PACKS)에 모여 있다 |
| `index.html` | 화면. 브랜드 이름은 `<script id="brands">` 블록에만 있다 (후원 시 이 블록만 교체) |
| `scene3d.js` | 3D 장면 (Three.js 로우폴리 미니어처). 집마다 방 크기·벽·바닥, 지역별 바깥 풍경, 시간대 조명, 계절, 캐릭터·직원·택배·이사 연출 |
| `scene.js` | 2D 픽셀 장면. WebGL을 못 쓰는 기기에서만 대신 쓰임 |
| `vendor/three.min.js` | Three.js r149 (MIT, `vendor/three.LICENSE`) |
| `sim/simulate.js` | 밸런스 시뮬레이션 |
| `build.js` | 한 파일짜리 빌드 |

## 들어간 것

**시작**: 제목 화면(뒤에서 3D 집이 돌며 낮밤이 바뀜) → 지역 → 집(가장 싼 집 / 한 단계 위 집) → 장르·채널 이름·특성 → 시작 세트(모의 결제)

**지역 4곳**: 도시·농촌·바닷가·산속. 시작 자금, 노출, 알바 시급, 협찬, 휴식 회복이 다르고 지역 전용 주제(경쟁 낮음)와 지역 이벤트 2종씩. 계절마다 지역 주제 반응이 다름(바닷가 여름, 산속 가을·겨울, 농촌 봄·가을)

**집 18곳**: 지역마다 4~5단계(예: 도시 고시원 → 원룸 → 오피스텔 → 스튜디오 사무실 → 강남 사옥). 월세, 이사 비용, 필요 구독자, 딸린 가구, 집 효과, 직원 책상 수. 이사하면 3일간 작업 불가, 월세 두 달 밀리면 가장 싼 집으로

**장르 4종**: 정보·교육, 게임, 먹방·일상, 음악·커버. 조회수·단가·전환·롱테일·바이럴·AI 촬영 티·마이크 효과·협찬·주제가 다름

**핵심 루프**: 트렌드 카드 → 기획·촬영·편집(단계마다 직접 / AI / 직원) → 썸네일 3안 → 업로드 → 72시간 피크 + 롱테일 → 정산. 방을 탭하면 작업 독려

**AI 제작**: 요금제 4단계, 크레딧, 숙련 5레벨, AI 티·워터마크, AI 생성 표시 의무와 적발, 요금 인상·모델 업데이트 이벤트, 전용 AI 모델 학습

**직원**: 작가·촬영 스태프·편집자·매니저·AI 오퍼레이터·커뮤니티 매니저. 능력·월급·기분·AI 거부감, 퇴사 통보. 3D에서 자기 책상에 앉아 일함

**수익**: 제휴 링크 → 광고(구독자 1천 + 시청 4천 시간), 협찬, 라이브(3천), 멤버십(3천, 30일 정산), 굿즈(5만), MCN 수익 배분

**후반·엔딩**: 채널 매각 제안(30만) / MCN 설립·영입·독립 요구, 상장(소속 10명 + 총 500만) / AI 스튜디오(전용 모델 + 300만 + AI 영상 300편). 엔딩 후 뉴게임+

**생활 (v0.3 1차)**: 배부름·청결·기분 → 컨디션(최상이면 품질·작업 속도 ↑). 냉장고·침대·문을 눌러 요리·배달·외식·샤워·청소·산책·통화·게임. 방치해도 라면·샤워는 알아서. 생활 자동화(도시락 배송·로봇청소기·커피머신·가사 도우미). 자세한 내용은 `docs/design-v0.3-life.md`

**화면**: 아래 메뉴창은 반 화면으로 열리고(방이 위에 보임) 위로 끌면 전체 화면

**그 밖**: 체력·번아웃, 알바, 자동 반복 루틴, 편집 외주, 시청자 피로도, 계절(120일 = 1년), 이벤트 15종 이상, 목표 18개, 자동 저장과 접속 안 한 동안 정산, 저사양 그래픽 모드, 영상별 클릭률·평균 시청 시간

## 밸런스 측정값 (봇, 1배속, 탭 없음)

생활 시스템 이후 (12판 중앙값, 60분): 도시·무료 — 생활 잘 챙김 7.2천 · 방치 5.4천 / 지역 도시 7.2천 · 농촌 1만 · 바닷가 7.7천 · 산속 1.4만 / 크리에이터 풀세트(₩2,200) 약 3~4배 (30판 중앙값 3.3배) · 입문 PC 팩 약 2.5배

10시간 측정값은 생활 시스템 전 기준(1시간 5천 → 3시간 36만 → 10시간 308만)이라 다시 재야 한다.

## 설계서 v0.2와 달라진 점 (설계서 반영 필요)

| 항목 | 설계서 v0.2 | 시제품 | 이유 |
| --- | --- | --- | --- |
| 조회수 공식 | `B × S^0.8 × …` | `B × 지역 × (2000 + 20×S)^0.7 × … × 피로도` | 원래 식은 구독자 0이면 조회수 0. 지수 0.8 이상은 후반 폭주 |
| 구독 전환율 | 1%, 품질 80 이상 2% | `0.8% × 품질/60 + 초반 보정` ÷ (1 + 구독자/30만) | 첫 영상 목표, 후반 폭주 방지 |
| 알고리즘 호감도 | CTR·AVD 7일 이동평균 | 업로드마다 품질·썸네일 기반 목표값으로 20% 이동 | 임시 규칙 |
| 바이럴 | 품질 80 이상, 10~50배 | 품질별 확률, 5~20배, 장르 배율 | 연쇄 폭주 방지 |
| AI 숙련 | 10/30/80/200편 | 15/50/150/400편, 시간 배율 완화 | 후반 폭주 방지 |
| 시청자 피로도 | AI 스튜디오 루트 리스크로만 | 모든 채널: 하루 0.5편 넘게 올리면 편당 조회수 감소 | 생산량이 무한히 조회수로 바뀌지 않게 |
| 시작 선택 | 장르 + 특성 | 지역 + 집 + 장르 + 특성 + 시작 세트 | 사용자 요청 |
| 공간 | 원룸·작업실·스튜디오·사옥 4단계 | 지역별 집 18곳 + 방 꾸미기 4단계 | 사용자 요청 |
| 결제 모델 | 편의 기능만 | 장비·컴퓨터·공간·강의 묶음 (게임머니로도 살 수 있는 것만) | 사용자 결정 |
| 이벤트 주기 | 3~7일 | 25~50일 | 3~7일은 30~70초마다 팝업 |
| 1단계 목표 | 30분/60분 불일치 | 60분 1만 | 사용자 결정 |
| 다채널 운영 | 구독자 3만, 두 번째 채널 | 없음 (MCN 소속 크리에이터로 대신) | 시제품 범위 |
| 그래픽 | 1단계 CSS 카드, 3단계 스프라이트 | 처음부터 3D 미니어처 방 | 사용자 요청 |
| 생활 요소 | 없음 | 배부름·청결·기분·컨디션, 생활 행동·자동화 | 사용자 피드백 (영상 하나만 만들어 심심함) |
| 크리에이터 풀세트 | — | ₩2,200: 입문 PC 팩 + 링라이트 + 방음 커튼 | 카메라·마이크를 넣으면 무료의 5~9배 |
| 파일 구성 | 단일 HTML | 여러 파일 + 한 파일 빌드 | 시뮬레이션과 엔진 공유 |

## 알려진 한계

- 후반 밸런스는 단순한 봇으로만 확인했다. 사람이 직접 하면 다를 수 있다.
- 휴대폰 실기기 성능은 확인하지 못했다 (느리면 기록 → 저사양 그래픽).
- 그래픽은 코드로 만든 기본 도형이다. 출시 수준은 3D 모델 에셋과 게임 엔진(Unity·Godot)이 필요하다.
