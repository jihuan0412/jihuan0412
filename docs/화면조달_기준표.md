# 각도별 화면 조달 기준표

작성일: 2026-09-03
전제: `docs/기획서.md` 2절(저작권 규정), `docs/파이프라인_설계.md` S0·S3
용도: S0 소재 발굴 시 `후보.json`의 `화면조달` 필드를 채우는 기준.
      **후보를 뽑는 시점에 화면이 정해져야 한다.** 대본을 다 쓰고 나서
      쓸 화면이 없다는 걸 알게 되면 그때까지의 리서치가 전부 매몰비용이 된다.

## 0. 화면 소스 등급

| 등급 | 소스 | 비용 | 리스크 |
|---|---|---|---|
| A | 배급사 공식 예고편 | 0 | 최저 (홍보 목적 공개) |
| A | 배급사 배포 스틸컷 (보도자료용) | 0 | 최저 |
| A | 공식 메이킹 필름·비하인드 (배급사/제작사 채널 공개분) | 0 | 낮음 |
| A | 시사회·무대인사·레드카펫 공식 영상 | 0 | 낮음 |
| A | 감독·배우 공식 인터뷰 클립 (언론사/배급사 공식 채널) | 0 | 낮음 |
| A | 자체 제작 화면 (타이포그래피, 연표, 지도, 도식) | 0 | 없음 |
| A | 생성 이미지 — **배경·분위기 컷 한정** | 0 | 없음 |
| B | 퍼블릭 도메인 자료 (오래된 인물 사진, 고문헌 등) | 0 | 낮음 (개별 확인 필요) |
| C | 라이선스 구매 이미지 (Getty, Shutterstock 등) | 유료 | 없음 |
| X | 본편 영상 캡처·클립 | — | **사용 금지** |
| X | 언론사 촬영 인물 사진 무단 사용 | — | **사용 금지** |
| X | 타 채널 영상 재편집 | — | **사용 금지** |

**생성 이미지에 대한 제한**: 실존 인물의 얼굴을 생성해서 쓰지 않는다.
배경, 시대 분위기, 추상 컷에만 쓴다. 인물을 생성하면 허위 이미지 문제가 되고,
이건 저작권보다 나쁜 리스크다.

**판단이 애매한 소스** (사용 전 개별 확인 필요, 기본값은 보류):
- 원작 소설 표지 / 웹툰 컷 — 표지 이미지의 인용 범위가 명확하지 않음
- 옛 신문 지면 이미지 — 지면 자체는 언론사 저작물
  → **우회: 헤드라인 문구를 타이포그래피로 재구성한다.** 사실 전달이므로 안전하고,
    화면도 오히려 더 깔끔하게 나온다

## 0-1. 인물 화면 없는 표준 구성 (무얼굴 구성)

인물 비화에서 **그 인물의 얼굴은 필수가 아니다.** 이야기는 나레이션이 끌고 가고,
화면은 시선을 붙잡는 역할만 하면 된다. 얼굴 사진에 의존하지 않는 표준 구성을 정의해 둔다.
이 구성을 쓰면 각도 1(원작자)과 각도 4(캐스팅)의 라이선스 비용이 0이 된다.

### 화면 구성 요소 (전부 A등급)

| 요소 | 용도 | 대략 컷 수 |
|---|---|---|
| 작품 공식 예고편 | 작품 특정 + 본문 내내 재활용 | 6~8 |
| 타이포그래피 | 인물 발언 인용, 연표, 집필·제작 기간 | 3~5 |
| 데이터 도식 | 연재 기간, 판매 부수, 개작 횟수, 흥행 수치 | 2~3 |
| 생성 배경 컷 | 시대 분위기, 장소, 추상 이미지 (**인물 금지**) | 3~4 |

쇼츠는 2~4초마다 화면이 바뀌어야 하므로 45초 본문에 12~18컷이 필요하다.
위 네 종류만으로 채워진다. **라이선스 구매 없이 성립한다.**

### 잃는 것과 보완

얼굴이 한 번도 나오지 않으면 "이 사람이 누구인가"의 각인이 약해진다.
얼굴은 가장 빠른 각인 수단이다.

- **보완: 훅(0~2초)에서 인물 이름을 화면 텍스트로 크게 박는다.**
  얼굴 대신 이름이 각인점 역할을 한다.
- 본문 중반에 이름을 한 번 더 노출한다 (타이포그래피 컷 활용)

### 얼굴이 실제로 필요한 경우

**비화의 반전 자체가 외모·이미지에 걸려 있을 때만** 얼굴이 필수다.
(예: 작품의 인상과 실제 인물의 인상이 정반대라는 것이 비화의 핵심인 경우)

이런 후보는 두 갈래로 처리한다.
- 공식 인터뷰 영상·퍼블릭 도메인 자료가 있으면 → 채택
- 없으면 → 라이선스 구매 대상. **1단계에서는 보류**

그 외의 모든 인물 비화는 무얼굴 구성으로 간다.

## 1. 각도별 표준 구성

### 각도 3 — 촬영 비화  ★ 1단계 주력

| 항목 | 내용 |
|---|---|
| 원가 | **가장 낮음** (A등급만으로 완결 가능) |
| 작품 특정 (2~10초) | 공식 예고편 |
| 본문 (10~45초) | 공식 메이킹 필름 + 무대인사·인터뷰 클립 + 타이포그래피 |
| 조달 실패 조건 | 해당 작품의 메이킹·비하인드가 공식 공개되지 않은 경우 |
| S0 확인 항목 | 배급사/제작사 공식 채널에 비하인드 영상이 있는가 |

사고, 즉흥 연기, 예산 문제 같은 비화는 메이킹 필름과 인터뷰에 그대로 근거가 남아 있다.
**화면과 근거가 같은 곳에서 나오므로 S1 검증도 함께 쉬워진다.** 1단계 주력으로 삼는다.

---

### 각도 5 — 작품 간 비교·연결  ★ 1단계 주력

| 항목 | 내용 |
|---|---|
| 원가 | **가장 낮음** (예고편 조합만으로 완결) |
| 작품 특정 | 예고편 2편 (전작 + 해당작) |
| 본문 | 두 예고편의 대응 장면 교차 + 타이포그래피 |
| 조달 실패 조건 | 전작 예고편이 온라인에 없는 경우 (구작에서 발생) |
| S0 확인 항목 | 비교 대상 두 작품의 예고편이 모두 접근 가능한가 |

화면 구성이 가장 단순하고 시각적 대비가 강해 쇼츠에 잘 맞는다.
**단, 소재가 "연출 취향의 반복" 수준이면 게이트 1(흥미도)에서 떨어진다.**
연결형 유형에 해당하려면 "몰랐던 두 작품이 이어진다"는 낙차가 있어야 한다.

---

### 각도 2 — 제작 계기

| 항목 | 내용 |
|---|---|
| 원가 | **중간** |
| 작품 특정 | 공식 예고편 |
| 본문 | 감독 공식 인터뷰 클립 + 실제 사건의 **타이포그래피 재구성** + 자료 도식 |
| 조달 실패 조건 | 감독이 그 계기를 공개적으로 말한 영상·기사가 없는 경우 |
| S0 확인 항목 | 감독 본인의 발언이 1차 소스로 존재하는가 |

실제 사건을 다룰 때 신문 지면 이미지를 쓰고 싶어지지만 쓰지 않는다.
**헤드라인·날짜·수치를 타이포그래피로 재구성한다.** 저작권도 피하고 가독성도 낫다.

---

### 각도 4 — 캐스팅 비화

| 항목 | 내용 |
|---|---|
| 원가 | **0** (무얼굴 구성 + 예고편 대체) |
| 작품 특정 | 공식 예고편 |
| 본문 | **핵심 우회: 인물 사진 대신 그 배우가 나온 다른 작품의 공식 예고편을 쓴다** |
| 조달 실패 조건 | 비화의 반전이 배우의 외모·이미지 자체에 걸려 있고, 공식 영상이 없는 경우 |
| S0 확인 항목 | 언급되는 배우의 예고편 화면이 확보되는가. 안 되면 무얼굴 구성으로 갈 수 있는가 |

배우 사진의 저작권은 촬영 언론사·스튜디오에 있고, 이게 실무에서 가장 자주 걸리는 지점이다.
**"거절한 배우 A" 를 보여줄 때 A의 사진이 아니라 A가 출연한 작품의 예고편 컷을 쓰면
라이선스 비용이 0이 된다.** 예고편도 구할 수 없으면 0-1의 무얼굴 구성으로 넘어간다.
두 방법이 모두 막히는 경우는 비화의 반전이 외모 자체에 걸려 있을 때뿐이다.

---

### 각도 1 — 원작자·작가 이야기

| 항목 | 내용 |
|---|---|
| 원가 | **0** (무얼굴 구성으로 성립) |
| 작품 특정 (2~10초) | 공식 예고편 |
| 본문 (10~45초) | 0-1 무얼굴 구성 — 예고편 재활용 + 작가 발언 타이포그래피 + 집필 연표·데이터 도식 + 시대·장소 생성 배경 컷 |
| 보너스 | 작가 공식 인터뷰 영상이 있으면 삽입 (필수 아님) |
| 조달 실패 조건 | 비화의 반전이 작가의 외모·이미지에 걸려 있고 공식 영상이 없는 경우 |
| S0 확인 항목 | 작가의 발언이 인용 가능한 형태로 남아 있는가 (타이포그래피 소재 확보) |

기획서의 우선순위 1위. **초판에서는 "작가 얼굴 = 라이선스 필수" 로 보고 원가 최고로 분류했으나,
얼굴은 필수가 아니다.** 나레이션이 이야기를 끌고 가고 화면은 무얼굴 구성으로 채우면 원가는 0이다.

이 각도의 실제 병목은 화면이 아니라 **인용 가능한 작가 발언**이다.
집필 계기·개인사를 작가 본인이 말한 기록이 남아 있어야 타이포그래피 컷이 만들어지고,
동시에 S1 사실 검증의 1차 소스가 된다. **S0에서 이걸 확인한다.**

## 2. 원가 요약

무얼굴 구성(0-1)을 표준으로 채택하면 **다섯 각도가 모두 원가 0으로 내려온다.**
남는 변수는 원가가 아니라 **소재 확보 난이도**다.

| 각도 | 원가 | 실제 병목 | 1단계 |
|---|---|---|---|
| 작품 간 비교·연결 | 0 | 비교 대상 두 작품의 예고편 확보 | ○ |
| 촬영 비화 | 0 | 공식 메이킹·비하인드 존재 여부 | ○ |
| 제작 계기 | 0 | 감독 본인 발언의 1차 소스 | ○ |
| 캐스팅 비화 | 0 | 언급 배우의 예고편 화면 | ○ |
| 원작자·작가 | 0 | **인용 가능한 작가 발언** | ○ |

**라이선스 구매가 필요한 경우는 단 하나로 좁혀진다** — 비화의 반전이 인물의 외모·이미지
자체에 걸려 있고, 공식 영상이나 퍼블릭 도메인 자료가 없을 때. 이런 후보는 1단계에서 보류한다.

## 3. 1단계 10편 각도 배분 (제안)

원가가 각도 선택의 변수에서 빠졌으므로, 배분은 **소재 확보 난이도**와
**각도별 실험 가치**로만 정한다.

| 각도 | 편수 | 근거 |
|---|---|---|
| 촬영 비화 | 3 | 소재 가장 풍부, 화면 근거와 사실 근거가 같은 영상에서 나와 검증도 쉬움 |
| 작품 간 비교·연결 | 3 | 예고편 조합만으로 완결, 시각적 대비 강함 |
| 원작자·작가 | 2 | 기획서 우선순위 1위. 무얼굴 구성으로 원가가 해소되어 1단계 투입 |
| 제작 계기 | 1 | 스토리 밀도 높으나 감독 1차 발언 확보가 조건 |
| 캐스팅 비화 | 1 | 반응 탐색용 |

**각 각도가 최소 1편 이상 들어가야 비교가 가능하다.** 한 각도에 몰면
그 각도가 실패했을 때 다음에 뭘 해야 할지 알 수 없다.

## 4. S0 체크리스트

후보 1건을 `후보.json`에 올리기 전에 아래를 전부 통과해야 한다.

- [ ] 각도가 5종 중 하나로 분류되는가
- [ ] 이 표의 "S0 확인 항목"을 통과하는가
- [ ] 45초를 채울 화면이 A등급 소스만으로 구성되는가
      (인물 비화라면 0-1 무얼굴 구성으로 12~18컷이 나오는가)
- [ ] 비화의 반전이 인물의 외모·이미지에 걸려 있지는 않은가
      (걸려 있고 공식 영상이 없으면 → 1단계 보류)
- [ ] X등급 소스에 의존하지 않는가
- [ ] 출처 URL이 기록되었는가

하나라도 미달이면 `00_후보풀/기각목록.md`에 사유와 함께 남긴다.
